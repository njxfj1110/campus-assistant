# 新生报到指南（示例数据，替换成你学校的真实信息）

报到时间：每年 9 月第一周，具体以录取通知书为准。
报到地点：学校体育馆，门口有各院系指引牌。

报到需要带的材料：
1. 录取通知书原件
2. 身份证原件及复印件
3. 一寸免冠照片 8 张（白底蓝底均可）
4. 高中毕业证原件
5. 户口迁移证（需要迁户口的同学才带）

办理流程：
1. 到所在院系报到点签到，领取校园卡和宿舍钥匙
2. 到体育馆缴费处缴纳学费和住宿费（支持刷卡和线上支付）
3. 到行李领取处领取军训服装
4. 到宿舍楼办理入住

其他提示：
- 学校门口和火车站均有迎新志愿者接站，校车免费接送新生和家长
- 校园卡是集门禁、就餐、图书馆借书于一体的卡片，遗失后到卡务中心挂失补办
