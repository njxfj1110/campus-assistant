# 长沙理工大学 选课指南

> 采集时间：2026-08-10
> 来源：教务处《关于认真组织2025-2026学年第一学期选课工作的通知》https://www.csust.edu.cn/jwc/info/1101/7078.htm 、《学生选课操作手册》https://www.csust.edu.cn/jwc//info/1133/3558.htm
> ⚠️ 选课各阶段日期每学期不同，以下以 2025-2026 第一学期为例，每学期需按新通知更新

## 教务系统入口
- 选课系统：http://xk.csust.edu.cn （用学号登录，首次登录初始密码一般为身份证后六位）
- 教务处官网：https://www.csust.edu.cn/jwc/
- 推荐使用 IE9 以上浏览器或 360 极速模式

## 选课时间安排（以 2025-2026 第一学期为例）
1. 正常选课：6月4日8:30—6月10日24:00，可自由选课，可补选、改选、退选
2. 公选课抽签：6月11日12:00后可查抽签结果，14:00—23:00 为公选课退课时间
3. 开学补选：9月9日8:30—23:00，全校开放，只能补选不能改退
4. 重修补选：9月11日8:30—23:00
5. 特殊情况选课：9月17日—9月24日

## 选课规则
1. 必修、限选课程由教务处按行政班批量机选，不用自己选
2. 必须自己选的：体育课、专业选修课、全校通识教育类选修课（公选课）
3. 公选课先预选最多 2 门，再抽签决定
4. 特殊情况选课对象：重修替代、刷分重修、毕业班少学分补选等，部分需缴费（本部约 80 元/学分）

## 选课操作流程
1. 正常选课：培养管理 → 选课管理 → 学生选课中心 → 进入选课
2. 重修报名：考试报名 → 成绩管理 → 重修报名选课 → 报名并缴费（"长沙理工大学计划财务处"公众号）
3. 特殊选课：培养管理 → 选课管理 → 特殊选课申请
